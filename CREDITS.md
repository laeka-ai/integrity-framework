# Credits

The Integrity Framework borrows ideas from these open projects. Thank you to their authors.

## Ideas and code we borrowed

- [affaan-m/ecc](https://github.com/affaan-m/ecc): inspiration for the Backstage scanner layer
- [affaan-m/everything-claude-code](https://github.com/affaan-m/everything-claude-code): hook profile pattern
- [alidaram99/exactground](https://github.com/alidaram99/exactground): look-alike package policy (rules rewritten)
- [alirezarezvani/claude-skills](https://github.com/alirezarezvani/claude-skills): lineage of the Samourai skills
- [aminblg/simpleenglish](https://github.com/aminblg/simpleenglish): punctuation that names the relation
- [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official): official Claude Code plugins (frontend-design, code-review, security-guidance)
- [anthropics/skills](https://github.com/anthropics/skills): skills adapted into this project
- [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd): answer-first reply style, adapted from its SKILL.md
- [baselane-sh/mods](https://github.com/baselane-sh/mods): context-meter mod
- [chaitanyagiri/munder-difflin](https://github.com/chaitanyagiri/munder-difflin): circuit breaker logic, ported to a hook
- [daiostech/parrhesia](https://github.com/daiostech/parrhesia): sycophancy benchmark scenarios and rubric
- [danielmiessler/lifeos](https://github.com/danielmiessler/lifeos): Bitter Pill and Doctor mechanisms
- [dewinator/mycelium](https://github.com/dewinator/mycelium): hard fork that became the engram memory engine
- [dietrichgebert/ponytail](https://github.com/dietrichgebert/ponytail): write the least code that solves the task (ponytail skill)
- [emilkowalski/skills](https://github.com/emilkowalski/skills): phone-first baseline, variant picker
- [esengine/deepseek-reasonix](https://github.com/esengine/deepseek-reasonix): compaction thresholds and fixed-section summary template
- [jakeschincariol/founder-skill](https://github.com/jakeschincariol/founder-skill): the founder skill pack (board, offer, pricing, CFO...)
- [mattpocock/skills](https://github.com/mattpocock/skills): writing for agents: the target before the prohibition
- [nousresearch/hermes-agent](https://github.com/nousresearch/hermes-agent): forked as the base of the Atlas agent
- [nutlope/hallmark](https://github.com/nutlope/hallmark): scored six-axis critique next to the deliverable
- [obra/superpowers](https://github.com/obra/superpowers): engineering skills forked (MIT)
- [omnigent-ai/omnigent](https://github.com/omnigent-ai/omnigent): an effect applies only on explicit accept
- [onewave-ai/claude-code-mods](https://github.com/onewave-ai/claude-code-mods): burn-meter mod
- [pbakaus/impeccable](https://github.com/pbakaus/impeccable): the impeccable design plugin
- [pullboard-dev/pullboard](https://github.com/pullboard-dev/pullboard): blueprints per project type; the bar frozen when work starts; one line per requirement with its gate
- [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem): skills adapted into this project
- [wynelson94/longhand](https://github.com/wynelson94/longhand): JSONL parsing and output-cap patterns
